# Food for Thought

A working prototype of **Food for Thought**, a personal food-guidance app built for INFO 3160.

Participants set their goals, eating pattern and restrictions, then get a day of meals. Each meal comes with a one-sentence reason it fits them, and they can keep it, swap it or say it's not for them.

## Features

- **Profile setup:** up to 3 goals, eating pattern (omnivore to vegan), restrictions and allergies, and a plain-language description of what they usually eat.
- **Today:** meals grouped by Breakfast, Lunch, Dinner and Snack. Each card shows the dish, a short reason, and Keep and Swap. Ingredients, nutrients and "Not for me" are in Details.
- **May be missing:** up to 3 nutrients or food groups the diet may lack, with foods that help.
- **Nutrition charts:** protein, fiber, iron, calcium and B12 as a share of general daily values, for each day and each meal. The participant's goals are highlighted.
- **Week:** a Monday–Sunday calendar to plan ahead, review past days and reuse a past plan.
- **Restriction check:** every suggestion's ingredients are screened against the profile before it is shown. Anything that fails is replaced from a vetted built-in meal library.
- **Facilitator panel:** test tasks that tick off automatically with timings, a timestamped event log, CSV export, example past days, and a reset between participants.

## Running it

It's a single static file with no build step. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

## AI vs. built-in suggestions

When opened as a Claude artifact, plans are generated by Claude through the artifact runtime. Opened anywhere else (locally or on GitHub Pages), that runtime isn't available, so the app uses its built-in meal library instead and labels plans "Built-in suggestions". Everything else works the same.

## Data and privacy

Profiles, plans and the session log are stored only in the browser's `localStorage`. Nothing is sent to a server except the AI request when running as a Claude artifact.

## Disclaimer

Suggestions follow the Dietary Guidelines for Americans and USDA MyPlate. Nutrient values are estimates. This is a class prototype, not medical advice.
